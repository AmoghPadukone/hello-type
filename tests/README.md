# tests

Vitest suites in Node, mirroring `src/core/`. Run with `npm test` (or `npm run check` for typecheck + lint + tests).

- `core/glyphs/`: composition, join quality over all 676 letter pairs, fidelity to Apple's words.
- `core/print/`: print plan and settings, tube watertightness, file formats.

What each suite guards is listed in [docs/development.md](../docs/development.md#tests).
